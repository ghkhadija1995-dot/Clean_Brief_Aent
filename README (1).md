# 🧹 CleanBrief Agent

وكيل ذكاء اصطناعي يفحص جودة بياناتك، ينظفها تلقائياً، ويكتب لك خلاصة تنفيذية وتوصيات جاهزة للعرض على الإدارة — كل ذلك من واجهة ويب بسيطة، دون كتابة أي كود.

مبني لمحللي وعلماء البيانات الذين يحتاجون تنظيف ملفاتهم بسرعة والحصول على تقرير مفهوم بدل التعامل مع Excel أو أكواد تنظيف متفرقة.

---

## ✨ الميزات

- **كشف ترميز الملف تلقائياً** — يتعرف على ترميزات النصوص العربية والإنجليزية (UTF-8، Windows-1256، وغيرها) دون تدخل يدوي.
- **تنظيف تلقائي للبيانات** — تعبئة القيم المفقودة وحذف الصفوف المكررة.
- **خلاصة وتوصيات بالذكاء الاصطناعي** — تقرير تنفيذي مكتوب بأسلوب إداري عبر نموذج GPT-4o، بناءً على الأرقام الفعلية فقط (بدون هلوسة أو اختراع بيانات).
- **مؤشرات جودة واضحة** — عدد الصفوف قبل/بعد التنظيف، القيم المفقودة المعالجة، والتكرارات المحذوفة، معروضة كبطاقات.
- **تحميل فوري** — الملف النظيف جاهز للتنزيل مباشرة من الواجهة.

## 🚀 التشغيل محلياً

### 1. استنساخ المستودع

```bash
git clone https://github.com/<username>/<repo-name>.git
cd <repo-name>
```

### 2. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 3. تشغيل التطبيق

```bash
streamlit run app.py
```

### 4. مفتاح OpenAI API

عند فتح التطبيق، أدخل مفتاح OpenAI API الخاص بك في الشريط الجانبي (لا يُحفظ أو يُشارك، يُستخدم فقط أثناء الجلسة الحالية).

> للحصول على مفتاح: [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

## 📋 طريقة الاستخدام

1. ارفع ملف بصيغة `CSV` أو `Excel` (`.xlsx`/`.xls`).
2. اكتب سؤالك عن الملف (اختياري) — مثلاً "ما أداء المبيعات هذا الربع؟".
3. اضغط **تشغيل التحليل**.
4. استعرض المؤشرات، الخلاصة التنفيذية، والتوصيات في التبويبات.
5. حمّل نسخة البيانات النظيفة بضغطة زر.

## ⚠️ ملاحظات

- الملفات المدعومة حالياً: `CSV`, `XLSX`, `XLS` فقط.
- يتطلب التطبيق مفتاح OpenAI API صالحاً لتوليد الخلاصة والتوصيات؛ تنظيف البيانات وحساب المؤشرات يعمل بشكل مستقل عن النموذج.
- لا يُنصح بمشاركة ملفات تحتوي بيانات حساسة عبر نموذج خارجي دون مراجعة سياسات الخصوصية الخاصة بمزود النموذج.
